# Frozen empirical method hypothesis

The learned object is a measured-activity regressor on the two reported nucleotide strands, positional chemistry names, terminal groups, observed concentration and explicit missingness. The GNN learns conventional relation-conditioned messages along directed backbones and an antiparallel alignment inferred from the two sequences. These edges are modeling assumptions, not measured conformations. Its scalar output is the expected recorded inhibition fraction under the available context; named chemical effects are differences of predictions for two actually measured, matched molecules.

The transfer question is whether this conventional learned representation improves source-family-held-out activity and chemistry-effect prediction beyond strong guide ridge/pairwise features, chemistry tokens, a tree model and a controlled node network with the same input fields and capacity. The APP family is wholly held out from training, validation, calibration and model selection. This simultaneously changes chemistry and assay/source distributions; it does not isolate any one cause of error. Unreported assay covariates in ENsiRNA remain missing.

The message-passing versus node-only ablation tests whether neighboring nucleotide states help beyond positional chemistry. The no-chemistry GNN ablation tests the added value of chemistry annotations. Models receive the same observed fields except named input ablations. Development chooses each candidate's configuration and duration, with three fresh final initialization seeds. The same measured rows and grouping weights are used by all controls. No test-driven restart, threshold or subset selection is allowed.

This is a conventional chemistry-aware GNN. ENsiRNA/ENsiRNA-mod already combines pretrained sequence information, geometry and chemistry (Tan et al., JMB 2025; pinned code 028824341635903f3c661f5d1cc737de106493d5). MEG-mod is another chemistry-aware graph precedent (Chen et al., JMC 2026, doi:10.1021/acs.jmedchem.6c00411; abstract scope only until full methods retrieved). Token models, multitask regression, factorized interactions and graph conditional neural processes are established alternatives. Here there is no response-conditioned support set, new interaction-transfer learning rule, new identifiability result or claim to reproduce a published 3-D method. A positive comparison would establish a bounded empirical finding, not architectural novelty.

Training has no admitted matched-pair loss because the primary-verified APP pairs are all held out. Pairwise losses are not introduced from test outcomes. B2 is a predicted-versus-measured pattern effect, not a molecular mechanism. No complete two-single-position B3 rectangle is admitted at freeze. Practical gain remains unspecified because screening-cost and development-assay utility information are insufficient.
