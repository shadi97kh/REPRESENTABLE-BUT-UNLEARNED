# Attempted contrast-range method: complete result and limits

Status: implemented and checked as a small exact reference. Standard finite-dimensional optimal recovery, not a new learned layer. G1 fails for this concrete candidate. The stronger requested result about end-to-end interaction learning remains unproved (G2 UNRESOLVED).

## Experiment and actual learner

A query fixes sequence background, chemistry-edit semantics, assay, concentration, time, response direction and control. Its four distinct *raw* states are indexed 00,10,01,11. The signed row is c=(1,-1,-1,1), giving I=c^T mu. A state reused in several queries has one coordinate in mu, not one coordinate per occurrence. Measured endpoint averages, population assay means and outputs of a fitted predictor are different mu choices. Their contrasts are consequently different targets. Molecular connectivity does not specify a causal DAG. A causal interpretation needs a justified intervention experiment, comparable conditions and biological assumptions not established here.

The actual learned predictor remains the v4 GraphModel: 64 ordered slots, 93 node features, eight directed adjacency channels and eight context fields; 93→32 embedding, two typed-message/self/residual/LayerNorm blocks with dropout .1 and masks, ordered 2048+8→64→1 readout, 153,345 parameters. For row states h, m_i=d_i^{-1}sum_rj A_rij h_j Wtilde_r, h_next=mask*LayerNorm[h+Dropout(ReLU(self(h)+m))]. R1 uses W2+support0*W0, W2+support1*W1, W2 and corresponding reverse base W5; pairing transforms are gated by training support. The no-message comparator replaces h_j by h_i while retaining degree, parameter count, support and readout. Source/feature/context preprocessing and weighted activity scale are fitted only on training rows. Held-out dropout is disabled.

Activity objective is sum_i w_i(z_i-(y_i-mu_T)/s_T)^2. Pair training adds lambda sum_p v_p[(z_1-z_0)-(y_1-y_0)/s_T]^2. For error e=z1-z0-delta_y/s_T the endpoint derivatives are +2 lambda v e for z1 and -2 lambda v e for z0. Both backpropagate into the same parameters; activity gradients add. Pair test labels never enter this loss. AdamW, clipping 5, batch128, weight decay1e-4, learning-rate selection from {1e-4,1e-3}, cap500/min50/patience50 and checkpoint selection are specified completely in the retained manuscript appendix. The v4 focused campaign has 432 development and 360 final fits; ten final seeds per block; 476,867 executed versus 166,067 selected-checkpoint updates. This investigation verifies and reuses those fits; it performs zero new model fits. Executable original training is retained in the evidence archive, not renamed as a new method.

The proposed addition takes exact finite observations and encoding-equivalence restrictions and returns extremes of a compatible response set. It does not differentiate through inference, adapt the GNN, or supply missing population-membership assumptions. It can diagnose a conditional identification range, not certify a biological effect from a fitted predictor.

## Precisely defined compatible class

Let S={1,...,n} be the finite union of all distinct raw endpoint states. Each coordinate includes the full relevant assay context. Given finite rational coordinate bounds l_i≤u_i, an observation matrix O and observation bounds a≤O mu≤b, define P_e by these inequalities plus |mu_i-mu_j|≤2 eta whenever the supplied encoding e maps states i,j into the same equivalence class. eta≥0 is an externally justified uniform response approximation allowance, not a fitted test residual. Inconsistent inequalities are allowed and produce EMPTY. Unknown chemistry must be represented by all admissible raw alternatives, not silently resolved to a zero annotation; finite alternatives can be retained through separate compatible polytopes. This reference does not solve the scientific problem of specifying that alternative set for siRNA.

The equivalence inequalities are exactly equivalent to existence of an unrestricted decoder g on the finite encoding classes and residuals r_i with mu_i=g(e_i)+r_i and |r_i|≤eta. Necessity follows from subtraction. For sufficiency, in each class choose g=(max_i mu_i+min_i mu_i)/2. The pairwise bound implies every residual has magnitude at most eta. This decoder class is an outer class for any specific neural readout satisfying the same residual bound; it is not a characterization of all realizable GNN weights. No result about training convergence follows.

The test cases use [-2,2] solely as declared synthetic finite-state bounds. No real activity value is clipped into that range. Real application of this theorem would require externally defensible bounds, observables, approximation and measurement errors; these are not presently established.

## Proposition: exact conditional finite-state outer range

For rational finite data as above and any rational query row c, if P_e is nonempty, `exact_range` returns exactly min_{mu in P_e} c^T mu and max_{mu in P_e} c^T mu, provided it completes all candidate active sets. For a finite collection of encodings/chemical alternatives, `union_range` returns the interval hull of their union of ranges. If any member computation is unresolved it returns UNRESOLVED; if every member is empty it returns EMPTY. It never replaces empty or unfinished optimization with [0,0].

If, on an event E, a population response mu* belongs to at least one retained P_e, all returned query intervals simultaneously contain their corresponding c^T mu*. Thus P(E)≥1-alpha implies simultaneous coverage at least 1-alpha. This conditional statement does not establish P(E) for learned representations, selected error bounds, or these siRNA data. It is a standard finite-set inclusion result, not the missing ML contribution.

### Complete proof

`exact_range` assembles A mu≤d, including upper/lower bounds for every coordinate, signed observation rows, and the signed class-difference rows. Duplicate left sides retain their smallest right side, which preserves the feasible set. Bounds make the set compact. A nonempty compact polytope has a vertex: successively maximize its first, second, ..., nth coordinate over the preceding maximizer face. Each step leaves a nonempty compact face. The final face is a singleton, hence a vertex of the original polytope.

At any vertex, active constraint normals span R^n. Otherwise choose nonzero v orthogonal to all active normals. Each inactive constraint has positive slack. Finitely many constraints allow a small positive t for which both mu+t v and mu-t v remain feasible (choose t smaller than slack/|A_i v| for all nonzero inactive inner products). The vertex would then be the midpoint of two distinct feasible points, a contradiction. Therefore some n active rows are linearly independent, including for lower-dimensional polytopes.

The algorithm visits every n-element subset of rows. Gaussian elimination returns the unique intersection for full-rank subsets and skips singular subsets. Every vertex is consequently considered. Each candidate is tested against every inequality in exact rational arithmetic, so an accepted candidate is feasible. A linear objective attains its extremum on the compact polytope. Its maximizer face has a vertex by the preceding coordinate argument; that vertex is also a vertex of the original polytope (a decomposition into feasible points would force both points into the maximizing face). The same holds for the minimum. Taking extrema over all accepted candidates is thus exact. No accepted candidate implies an empty bounded polytope, not a zero target.

For finitely many polytopes, the minimum over their union is the least component minimum and the maximum is the greatest component maximum after discarding empty sets. The interval hull may include values between disconnected components; it is not asserted to equal a nonconvex identified set. An unresolved component prevents an outer certificate. For any mu* in one retained component, its objective lies within that component's extrema and hence within the hull. This holds simultaneously for any finite collection of query rows using the same mu*. Applying it on E proves the probability statement. This concludes the proof without a repository-only dependency.

### Data-dependent encoding and statistical membership

The deterministic argument is valid for the realized collection of encodings, even if data dependent. The missing premise is inclusion of truth. A union over a fixed library avoids dropping a valid member through model selection; a selected singleton can exclude truth. Neither device proves there exists a valid member. An example of a sufficient observation event, *if applicable*, is the following: endpoint k is a mean of r_k independent unbiased replicates with individual variance bounded by known v_k; choose alpha_k>0 with sum alpha_k≤alpha and t_k≥sqrt(v_k/(r_k alpha_k)). Chebyshev gives P(|barY_k-mu_k|>t_k)≤alpha_k and the union bound gives simultaneous endpoint coverage. Endpoints need not be independent across k. Independently justified coordinate/model bounds must also contain truth; if those are random, their failure budgets must be added. Learned eta cannot be justified by in-sample residuals. The retained assays do not supply all replicate/variance/model-error inputs needed for this construction, so it is not used to generate biological CIs.

Shared states are kept in a single vector. If covariance Sigma of measured endpoint errors were justified, query covariance would be C Sigma C^T, obtained by expanding E[(C epsilon)(C epsilon)^T]. It is not diagonal merely because query indices differ. No covariance is fabricated here. Prediction intervals for new noisy outcomes need additional observation-noise modeling; an identified-range hull is not such an interval. No exchangeability or arbitrary-shift guarantee is inferred.

### Arithmetic and complexity

The reference accepts only integers and explicit decimal/rational strings; nonfinite values and ambiguous float input are rejected. Decimal strings denote their exact rational values. Rational elimination and all feasibility/objective comparisons introduce no rounding error for the supplied problem. For measured or floating-point model inputs, uncertainty must enclose conversion error before such a certificate concerns the intended problem. Exact rational zero gap is not a claim that a float-trained network is symbolically exact. No dual optimizer runs: the certificate is exhaustive enumeration, so primal violation and global objective gap are exactly zero; a dual residual is inapplicable and saved as null.

For n states and m distinct inequalities, at most binomial(m,n) systems are processed, each using O(n^3+mn) rational operations. Storing V accepted vertices uses O(Vn+mn) rationals; evaluating Q additional objectives on the same stored vertices costs O(QVn). K alternative encodings multiply these costs in the worst case. Integer bit lengths can grow during elimination; the operation bound is not a bit-complexity or practical polynomial-time claim. The implementation stops before enumeration when binomial(m,n)>200000 and returns UNRESOLVED. It is useful only as a small exact reference and does not establish efficient learned interaction inference. No gradients through enumeration are supplied or claimed.

## Counterexamples and elementary implementation facts

1. If the multisets {e11,e00} and {e10,e01} coincide, every deterministic decoder has zero predictive contrast by pairwise cancellation of equal evaluations, counted with multiplicity. A constant encoder and true response mu=(0,0,0,1) show this does not imply biological zero. With eta=0 the truth is excluded; complete observations correctly make the class empty. With eta=1/2 and only 00,10,01 observed as zero, the range is [-1,1], retaining the missing effect.
2. For f_c(s,a,b)=m(s)+u(s)a+v(s)b+c q(s)ab, the last term is zero at 00,10,01 for every c. Direct subtraction cancels m,u,v and leaves I=c q(s). Missing joint observations cannot determine c. If q(s) varies, even arbitrarily variable fitted interactions are compatible; near-flat predictions are not forced.
3. If A_r is identically zero in every training graph and W_r is independently parameterized, W_r drops out of the forward computation and its data gradient is zero. Weight decay, optimizer state, initialization, shared bases or indirect coupling can still affect parameters. R1 shared bases receive gradients through other present routes. This statement does not show that the whole model cannot learn interactions. The actual conventional code is checked with one present and one absent route.
4. The quartic-plus-sextic p(x)=x^2-3x^4+x^6 has p'(0)=0 and p''(0)=2, so 0 is a strict local minimum, but p(1)=-1<p(0). A feasible local minimum is an upper bound on the true minimum, not a valid lower endpoint. Negating p gives the reversed upper-extremum counterexample. Two local neural optima yield inner witnesses unless additional certificates exist.
5. With independent coordinate errors in [-2,2], a shared reference cancels in (mu0-mu1)-(mu0-mu2)=mu2-mu1, yielding [-4,4]. Duplicating mu0 as independent variables would instead produce [-8,8] for a different experiment. Dependence is an observation property, not a model convenience.

These results explain the implementation and reject overclaims. They do not satisfy G2's requested *new* result about the trained adaptive learner. No performance pilot, new learned architecture or positive contribution is inferred from passing the checks.
