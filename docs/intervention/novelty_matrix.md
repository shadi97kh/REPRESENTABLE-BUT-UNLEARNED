# Novelty and predecessor audit

The proposed response-only operator is a graph conditional neural process. Its graph representation, identity centering, response loss, interaction loss and optional contrast loss do not presently establish a distinct ML mechanism. The defensible revised question is whether a specifically controlled auxiliary training objective improves adaptation to new predictor functions over the identical response-only CNP. That is an empirical hypothesis about an incremental method, not an established novelty claim.

The search cutoff is September 12, 2026. Primary papers and pinned author code support the comparisons below. Repository commits and file hashes are in `data/intervention_sources/author_code/manifest-v1.json` and `extra-v1.json`; paper hashes/versions are in `data/intervention_sources/papers/manifest-v1.json`. A retrieved repository is not evidence its implementation was run.

## Current-date search and unresolved references

The audit additionally checked the July 2026 [Unified Counterfactual Explainer](https://www.nature.com/articles/s44387-026-00135-w), which jointly considers topology, edge attributes and node features. Its article metadata and author repository route were located; complete implementation equivalence was not established, so it receives no invented operator-level comparison. The March 2026 [SPEX/ProxySPEX author update](https://bair.berkeley.edu/blog/2026/03/13/spex/) points to maintained implementations and reinforces the need for tree-surrogate controls.

Searches covered named predecessors, graph/function conditioning, graph counterfactuals, amortized graph-edit explanations and newer 2026 work. This is a bounded collision audit, not proof that no other paper exists. “Structured neural processes” was evaluated through CNP, CGNP and MPNP. “Grammar-guided local data” did not identify a unique paper after several exact-title and broader searches; that reference remains unresolved. SQUID was read as a separate named primary source. No claim of novelty in grammatical perturbation generation is made.

Exact graph-edit response regression is the common primary track. PGExplainer, FastSHAP, Selective Explanations and GraphSHAP-IQ retain their native estimands in a separate applicability table; converting their outputs into signed chemical effects without a valid reconstruction would create an unfair comparison. SPEX/ProxySPEX can instead reconstruct a fully valid binary value game, after which the same reference differences can be computed. On three binary edits the exact eight-state table is mandatory.

Continuation on a positive-method route would require a concrete mechanism beyond this CNP equivalence and positive predefined held-out evidence. A favorable auxiliary-loss result alone would not establish that the combination of losses is new. No training is recommended merely to seek a favorable seed.
