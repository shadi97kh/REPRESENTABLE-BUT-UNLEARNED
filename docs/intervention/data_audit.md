# Pinned delivery-lipid data and checkpoint audit

The primary application is a graph of an ionizable delivery lipid used in an mRNA delivery formulation. It is not an RNA secondary-structure graph. The audit preserves raw values and distinguishes reported delivery measurements from predictor-query responses. The [source manifest](../../data/intervention_sources/manifest-v1.json) pins repository commits, original paths, local copies and SHA256 values; all four starting CSV hashes match the supplied evidence file.

These are local RDKit 2026.03.1 calculations, using sanitized canonical isomeric SMILES without salt stripping, tautomer/protonation normalization or stereo imputation. AGILE's component counts remain 20/12/5 after canonicalization. Every row in these four files has at least one unspecified tetrahedral stereocenter. TransMA has 90 repeated-structure groups in train and 10 in test; every group contains conflicting HeLa labels. Train/test canonical and scaffold intersections are empty. The [initial audit](../../runs/intervention/audit-v1/audit.json) retains every conflicting structure and original label.

The important reconciliation is by experimental component code. AGILE and LANTERN share 1,100 isomeric canonical structures; a join on chemical identity produces 100 label disagreements. A join on the same component code instead gives agreement for all 1,100 labels within the declared 1e-6 tolerance, with 100 disagreements in product stereochemical representation. These are different joins and different findings. The current-file audit does not substantiate 100 same-code measurement errors. See the [reconciliation record](../../runs/intervention/audit-v2/reconciliation.json).

The [LANTERN CisTrans table](https://github.com/AsalMehradfar/LANTERN/blob/11240f29ef92323649ae60d177b21df77e2d428b/data/CisTrans.csv) includes 100 `C+T` entries and a representation containing two SMILES separated by ` + `. Its supplement describes the B4 mixture/B5 trans distinction. A single pure-product graph cannot stand in for both assay materials. The differing B4/B5 representations explain why chemical and experimental-code joins can disagree. This is an alignment issue requiring original chemical provenance, not a reason to average all conflicts as replicate noise. The [2026 journal paper](https://www.nature.com/articles/s44488-026-00007-x) discusses historical curation; its historical mismatch totals must not be assigned automatically to the pinned current files.

The original AGILE [source workbook](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41467-024-50619-z/MediaObjects/41467_2024_50619_MOESM4_ESM.xlsx) was retrieved with SHA256 `e795d4e7ef1ec5c82b0358c626ab1eae059b76485a3ebdb7cbe5565aa6aac723`. All 1,200 HeLa values in the grouped file agree with the Figure 2 grid. The A column headings are explicit; B-fast/C-slow row ordering is a declared mapping cross-checked against every value, because the grid does not explicitly label every B/C row. This numerical agreement supports value provenance but is not independent proof of each product's stereochemical identity. The July 2026 [current AGILE dataset release](https://zenodo.org/records/21422889) also contains 1,200 unique isomeric structures and agrees with the grouped file on all chemically joined labels.

The [AGILE methods](https://www.nature.com/articles/s41467-024-50619-z) specify initial high-throughput testing of crude, unpurified reaction products. Study-level formulation is ionizable lipid/DOPE/cholesterol/C14-PEG2000 at 35:16:46.5:2.5 molar parts, with firefly-luciferase mRNA, 0.1 microgram mRNA per well and a 24-hour readout. The endpoint is log2 of mean transfected-cell luminescence divided by mean untreated-cell luminescence. These fields are stored under `study_assay_provenance`; absent row-specific formulation, dose, cargo, timing and replicate fields remain null. Per-well deviations, individual replicate measurements, reused controls and per-row uncertainty are unavailable in the audited endpoint table. HeLa is the present audit endpoint; raw RAW264.7 values are retained where provided and are not pooled into it.

The [3,500-row provenance table](../../runs/intervention/audit-v2/rows.jsonl) records source URL/hash and row number, all raw fields, molecule/component identities, stereo ambiguity, scaffold, labels, duplicate/conflict status, study-level context separately from missing row fields, source-workbook cells where linked, and conditional pair eligibility. No measured edit pairs have been exported. Before pairing, group by verified experimental identity, mixture/pure status and comparable assay; quarantine conflicting structures and account for shared molecules/controls in uncertainty. Counting all rectangles as independent samples would inflate evidence.

The two small checkpoints were inspected using CPU `torch.load(..., weights_only=True)`, without forward evaluation or training. Their full SHA256 values are in the [supplement manifest](../../data/intervention_sources/supplement/manifest-v1.json); that acquisition-time manifest's `loaded_or_executed=false` predates the later metadata audit. Neither artifact is admitted as a held-out source predictor. The LANTERN inference fallback fits a scaler to supplied features, so it cannot be assumed to implement train-only preprocessing. An accompanying scaler route is present in the pinned tree, but its compatibility and fitting membership remain unverified. TransMA's [release inventory](../../data/intervention_sources/supplement/transma_release_inventory-v1.json) records archive URLs and sizes without retrieving them.

The TransMA scientific version read in full was [arXiv v1, July 2024](https://arxiv.org/abs/2407.05736v1). A [2025 journal version](https://doi.org/10.1093/bib/bbaf307) was identified, but its full text was not retrieved during this audit. The comparison therefore does not silently attribute every current-code detail to the earlier preprint. The multimodal graph/descriptor/3D representation requires its exact reconstruction pipeline before any legitimate query adapter; this preparation's four RDKit descriptors cannot substitute for it.

The separate [LipoBART route](https://github.com/Sanofi-Public/LipoBART/tree/1d792752944c87e2380e7a25af15f68d792bb3b6) is pinned at `1d792752944c87e2380e7a25af15f68d792bb3b6`. Its audited `iphos_multiclass.csv` has 572 rows, 572 valid unique primary molecules, and zero isomeric canonical overlap with AGILE. It contains `y1/y2` classification labels and `m1..m4/p1..p4` formulation fields; the source conversion code derives the binary class from `y1>=2` and identifies the underlying Liu 2021 route. The [LipoBART paper](https://doi.org/10.1093/bioinformatics/btae342) is a separate prediction task. Full assay provenance and comparable measured edit pairs remain unresolved; classification labels are not AGILE's continuous delivery endpoint.

The optional [RNAGym repository](https://github.com/MarksLab-DasLab/RNAGym/tree/2828cf99316d75daaa8d832a2573cbb25bbd35fe) is pinned at `2828cf99316d75daaa8d832a2573cbb25bbd35fe`. Its 70-entry reference file includes construct sequences and assay descriptions. The processed-assay download route was identified but not fetched or paired. No RNA measured-variant validation or delivery interpretation follows from this metadata. The [alternative-data audit](../../runs/intervention/alternative_data_audit-v1.json) keeps these limitations explicit.

A future predictive comparison must include freshly rebuilt fingerprints/descriptors with an MLP, ridge and boosted trees, plus applicable published models under verified preprocessing and membership. Unfitted interfaces are implemented. Source-model selection must use development predictive performance only, with train-only normalization and feature selection; test performance cannot select a model zoo. No trained GNN capability, predictive noninferiority, measured edit-effect agreement, ranking benefit or therapeutic utility has been demonstrated. These are separate gates from faithful approximation of a frozen predictor.
