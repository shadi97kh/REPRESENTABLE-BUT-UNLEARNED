Each holds for the section that cites it; none is assumed globally.

Assumptions A1–A5 are exactly the conditions under which the report's κ sentence

## Item 6 — affinity in `X` is not additivity in `z`

**The report said:** "sum + ReLU under non-negative parameters is *exactly*
affine, so nonlinearity cannot be inferred from weight norms" (C4, violation
2.157e−16).

**What C4 tested.** Reading `experiments/c4_affinity.py`, the additivity test is

```python
A = ...                                   # adjacency drawn once, HELD FIXED
lhs = m.forward(X1 + X2, A) - f0
rhs = (m.forward(X1, A) - f0) + (m.forward(X2, A) - f0)
```

This varies the **node features `X`** with the adjacency fixed. It establishes
affinity in `X`. It says nothing about additivity in `z`.

**Counter-fact, exact.** Three-node path, candidate edges `z₁ = (0,1)`,
`z₂ = (1,2)`, unit features, no bias, no self-loops, unit weights, sum readout,
two layers. Since `1ᵀA²1 = Σᵢ dᵢ²`:

| `z` | degrees | `f(z)` |
|---|---|---:|
| (0,0) | (0,0,0) | **0** |
| (1,0) | (1,1,0) | **2** |
| (0,1) | (0,1,1) | **2** |
| (1,1) | (1,2,1) | **6** |

so `f(z) = 2z₁ + 2z₂ + 2z₁z₂`, with **mixed difference 2**. Every preactivation
is non-negative, so **every ReLU is stable** — the interaction does not come from
clipping. It comes from adjacency-feature products, which is exactly the
separation the primary MPNN-verification literature makes.

**The actual model, on a real family.** Projecting the enumerated outputs of the
real `CertifiedModel` onto the design matrix `[1, z]` over all 20 feasible
structures of `GGGAAAUCC` gives a **relative residual of 2.4 × 10⁻²** for the
residual `g`. It is not additive in `z`.

**Scope now stated.** C4's result is `X`-affinity on the non-negative orthant and
is retained. It is **not** evidence that the residual carries no useful
structure. That question is separate and was never tested by C4.

**Consequence for the programme.** This is the single most important P0 finding
for the stated goal. The report used C4 to suggest the residual could not be
doing anything; that inference is invalid. Capacity for non-additive structure is
demonstrably present. Whether it **generalises** is what G4 measured and G4
failed — a different question, and the one P1 must address.

**Diagnostics to use from here (both, not either).** Feasible four-point mixed
differences where a fully feasible rectangle exists; and the `[1, z]`
design-matrix residual, which applies even when no such rectangle exists.
Tolerances must be scale-aware.

## Item 7 — layer 1: the message is affine, its ReLU is not exact

**The report said:** "Layer 1 needs no relaxation at all."

**The implementation is correct.** `ResidualBounder.propagate` computes the
layer-1 message with `_message_affine` (exactly affine — right) and then **does**
call `relu_bounds` on it. On a 12-node instance, layer 1 carries **2 unstable
units**, so the relaxation is not merely present but exercised.

The distinction the report lost: with fixed input features, the layer-1
*preactivation message* `M₁ = (B + Pz)Z₀` is affine in `z`. Its *activation* is
not thereby exact. `ReLU(z₁ + z₂ − 1)` takes values 0, 0, 0, 1 over the four
binary assignments — mixed difference 1, plainly non-additive.

**Verdict: prose error over correct code.** No code change needed; the sentence
must not survive into the paper.

**Also required.** Write the conditional cap as `q_e ≥ sup{ … }` — a certified
upper bound — unless the nonlinear conditional maximum is genuinely solved
exactly. The current implementation computes a bound, not the exact supremum.

## Item 8 — the walk-count identity is uniform-feature only

**Domain of validity.** For a shared-weight, bias-free, unnormalised sum network
with all ReLUs stable, **uniform** node features, a compatible linear readout and
positive output scale:

```
f(A) = c · 1ᵀ A^L 1 ,        κ_L(F) = ( 1ᵀ A_∪^L 1 ) / ( max_{G∈F} 1ᵀ A_G^L 1 )
```

Required alongside any use of this: whether `A` includes fixed backbone edges and
self-loops, and that the denominator is strictly positive.

**Exact counterexample to any feature-independent extension.** Candidate edges
`(0,1), (1,2), (3,4)`; `F` = all 6 matchings; `L = 2`; no self-loops.

| features | `1ᵀA_∪²x` | `max_G 1ᵀA_G²x` | ratio |
|---|---:|---:|---:|
| uniform `(1,1,1,1,1)` | 8 | 4 | **κ₂ = 2** |
| `(1, 1, 1, 1/10, 1/10)` | 31/5 | 11/5 | **31/11 ≈ 2.8182** |

All features strictly positive; no signed weights, no bias, no clipping. The
ratio **exceeds κ₂**, so κ_L does not bound the relaxation ratio for arbitrary
positive features. The uniform-feature identity is untouched.

**Restricted repair (supporting inequality, not a new theorem).** For
`x_min ≤ xᵢ ≤ x_max`, `x_min > 0`, bounding numerator by `x_max` and denominator
by `x_min`:

```
f(A_∪, x) / max_G f(A_G, x)  ≤  (x_max / x_min) · κ_L(F)
```

Verified exactly on the counterexample instance: observed 31/11 ≈ 2.818 against a
bound of 20. It is loose, and **vacuous at `x_min = 0`**.

**Also to correct.** Where a large-window denominator was a *sampled* maximum, it
is a lower bound on the true maximum, so the estimated κ is **above** the true
ratio — an over-estimate, not an exact characterisation. Stabilisation at 2,000
samples is not an optimality certificate. The C8/C9 observations on three window
lengths remain valid as empirical observations under that caveat.

## Item 9 — 0.912 per layer is not a universal constant

**Exact formulas.** For all matchings on `2m` vertices over the complete
candidate graph with uniform features (the union is `K_{2m}`; the maximum is
attained at a perfect matching, which is regular):

```
no self-loops:            κ_L = (2m − 1)^L
self-loop at every node:  κ_L = m^L
```

Both verified in exact arithmetic for `m = 1…4`, `L = 1,2,3`, against the maximum
over the **enumerated** matching family (`all_agree: true`). Worked values:
`m=3` gives κ₂ = 25 without self-loops and 9 with them; `m=2` gives 9 and 4.

**Consequence.** The exponent in `L` is `log(2m−1)` or `log(m)`: it depends on
the family and on the **self-loop convention**, not on depth alone. C5's fitted
0.912 per layer (R² 0.9996) remains a correct measurement **on the family C5
used**, over its finite range and with its chosen horizontal variable. It is not
an architectural constant, and the paper must derive the closed form for the
actual experiment before interpreting any fitted exponent.

### Under the convention the repository actually uses

`backbone_adjacency(n, self_loops=True, chain=True)` — and **every call site in
`scmp/` takes the defaults** (verified by inspection). So the fixed part is

```
B = I + chain(0-1-2-…-(n-1))
```

with candidate edges added on top. **Neither closed form applies**, because the
chain contributes edges present in every member, so the union and the maximum
share a fixed core and the ratio is compressed toward 1. Exact values, uniform
features, all matchings over the complete candidate graph:

| m | L | no self-loops | self-loops only | **ACTUAL: self-loops + chain** |
|---:|---:|---:|---:|---:|
| 2 | 1 | 3 | 2 | **11/7 ≈ 1.571** |
| 2 | 2 | 9 | 4 | **61/25 ≈ 2.440** |
| 2 | 3 | 27 | 8 | **169/45 ≈ 3.756** |
| 3 | 1 | 5 | 3 | **23/11 ≈ 2.091** |
| 3 | 2 | 25 | 9 | **177/41 ≈ 4.317** |
| 3 | 3 | 125 | 27 | **681/77 ≈ 8.844** |

The actual-convention values are **not powers** of any constant: for `m = 3` the
successive ratios are 2.064 then 2.048, approaching a limit from above rather
than sitting on `c^L`. So under the implemented convention there is **no clean
closed form at finite L**, only asymptotic geometric growth.

Consequences: any κ quoted for this model must be derived under `B`, never
borrowed from the candidate-only matching formula; and a fitted per-layer
exponent measured on one family under one `B` is even further from universal
than item 9's idealised comparison already showed.

**Three statements to keep apart**, which the report merged:

1. there **exists** a sequence of downward-closed families with unbounded gap;
2. **every** non-union-closed family has unbounded gap;
3. one **fixed finite** family has a particular gap.

C5 supports (1) and (3). It does not support (2). Separately: join closure is
*sufficient* for the union graph to be feasible; exactness for a particular
predictor does not by itself imply join closure.
