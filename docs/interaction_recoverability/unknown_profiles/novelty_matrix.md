**STANDARD RESULT APPLIED — reduction assessment.** The balanced known-profile weak-identification rate survives unchanged. In the extension, telescoping solves a known linear difference equation for each profile; truncation regularizes its inversion. DKW supplies observed-quantile uncertainty. A mean-value/diagonal-dominance inequality separates two unknown shifts, and the target is evaluated by ordinary plug-in integration. These components establish a special-case consistency bound, not a target-specific ML advantage. The same construction is available to every equally informed inverse-problem control.
