# P1 — repair the predictor before verifying it at scale

Generated by the `scmp.revision.predictor_pilot` module using `configs/revision_predictor.yaml`.
Records: `runs/revision/predictor_pilot-20260905-222454.json` (S0–S3) and
`runs/revision/predictor_pilot-20260905-223008.json` (S0, S4–S5), each with a
`.sha256` sidecar. Tests: `tests/revision/test_predictor_pilot.py` (16).

**Separation.** S0–S3 are **technical training diagnostics** on the Huesken rows.
They support no RNA claim. S4–S5 are **controlled synthetic** experiments on
enumerable non-RNA families; RNA data is excluded from them because the reporter
construct context is unresolved.

**Verdict up front.** The historical comparison was mis-specified and is now
explained. A-initialised residual training genuinely repairs the old setup. But
**useful nonlinear predictive value is not demonstrated**: on both interacting
tasks a plain pairwise ridge beats every neural arm, and on one it is exact. Per
the plan's own decision rule, this is a stop-and-redesign, not a scale-up.

## S2 — three defects, each shown by direct test

| Check | Verdict |
|---|---|
| label scaling | OK — values above 1.0 are legitimate and **not clipped** |
| readout scaling | OK — the phase-one 250,000× miscalibration has not recurred |
| gradients | OK — no dead parameter tensor in any arm |
| checkpoint loading | OK — `_i`/`_j` non-persistent, load is exact |
| **graph indexing** | **DEFECT** |
| **input parity** | **DEFECT** |
| **decomposition exercised** | **DEFECT** |

**`certifiable_gamma0` is graph-blind.** `f(A=I) == f(A=ones)` exactly. It is
`b(X)` alone — a per-node MLP summed over nodes. Its 0.7253 contains no graph
information at all.

**The certified decomposition was never exercised.** `run_pilot` builds
`CertifiedModel(d_in, tuple(), …)` with an **empty candidate set** and passes an
empty `z`, so `aᵀz ≡ 0` and `Pz = 0`. G4 did not test an anchor-plus-residual
over any family.

**Input parity fails.** The historical baseline has no route from `X` to the
output bypassing the adjacency; `gamma0` is entirely such a route. Adding only a
skip path moves the baseline **0.1212 → 0.3390**.

The four arms then read consistently, and not as the report told it:

| Arm | Graph path | Node-wise path | ρ |
|---|:-:|:-:|---:|
| `certifiable_gamma0` | ✗ | ✓ | **0.7253** |
| `certifiable_gamma1` | ✓ | ✓ | 0.4573 |
| `unconstrained_with_skip` | ✓ | ✓ | 0.3390 |
| `unconstrained` | ✓ | ✗ | 0.1212 |

Adding the node-wise path helps; adding the MFE-graph term **hurts**. The best
arm cannot see a graph. G4's failure is corroborated but its stated cause was
wrong: this is evidence that **the MFE adjacency is uninformative or harmful for
this label**, not that nonlinear residuals are useless.

## S4 — A-initialisation repairs the old setup

`path_matching`, interacting target, **size holdout** (train |z| ≤ 3, test |z| = 4).
Paired per-seed differences against `A_only`; negative is better.

| Arm | Test MSE | Δ vs A_only | 95% CI | Seeds won |
|---|---:|---:|---|:-:|
| `A_init_finetune` | 9.9644 | **−0.7329** | [−1.4306, −0.0351] | **5/5** |
| `A_init_frozen` | 10.3087 | **−0.3886** | [−0.7296, −0.0476] | **5/5** |
| `A_init_shrinkage` | 10.3265 | **−0.3708** | [−0.7259, −0.0157] | **5/5** |
| `A_only` | 10.6973 | — | — | — |
| `A_plus_B_old_setup` | 11.0686 | +0.3714 | [−0.0838, +0.8266] | **0/5** |

The **old setup is worse than the anchor alone on every seed**; every
A-initialised variant is better on every seed with a CI excluding zero. So the
historical residual failure was an initialisation and optimisation problem, and
A-initialisation fixes it. Mechanism verified: the residual output is zeroed
while hidden layers and the gate stay nonzero, `f` equals the anchor exactly at
initialisation, `readout.weight.grad ≠ 0`, and the γ=0 bypass survives
NaN-poisoning of the residual.

Shrinkage was selected on a slice of **train** only, never on test.

## S5 — but the residual is not useful

Paired against `A_only`. `ridge_pairwise` regresses on `[1, z, co-occurring products]`.

| Family \| target | Best arm | Its MSE | `A_init_residual` | Δ vs A_only | Seeds |
|---|---|---:|---:|---:|:-:|
| path_matching \| **interacting** | `ridge_pairwise` | **0.0000** | 10.3087 | −0.3886 | 5/5 |
| path_matching \| additive | `ridge_additive` | 0.0000 | 0.4510 | −0.1060 | 5/5 |
| layered_dag \| **interacting** | `ridge_pairwise` | 1.7952 | 2.6356 | −0.0098 | 1/5 |
| layered_dag \| additive | `ridge_additive` | 0.5710 | 3.8464 | +0.1471 | 2/5 |

**On path_matching the pairwise ridge is exact — MSE 0.0000, ρ 1.000 — while the
residual sits at 10.3087.** On layered_dag the residual gives no benefit at all
(1/5 seeds, CI spanning zero). The additive negative controls pass: the residual
does no significant harm there, which is what the plan asked for.

### Does the residual fit interactions? Quantitatively, partly

Projection onto `[1, z]` and feasible mixed differences, seed 0,
path_matching interacting target:

| Object | Projection residual | Max mixed difference |
|---|---:|---:|
| **the target** | 0.846 | 3.390 |
| `ridge_pairwise` fitted | 0.846 | 3.390 |
| `A_init_residual` fitted | **0.068** | **0.443** |
| `A_only` fitted | 2.6e−15 | 0.000 |

The residual learns **real but partial** interaction: about **8%** of the
target's projection residual and **13%** of its mixed-difference magnitude. Not
zero — so this is neither a dead path nor a bug. Far short — so a two-layer
sum-aggregation MPNN with one shared adjacency cannot represent arbitrary
pairwise edge interactions on this family.

### Answers to the three questions the stage had to settle

1. **Does it fit interactions?** Partially — 8–13% of the required magnitude.
2. **Does it generalise them?** Yes, marginally: under a size holdout it beats
   `A_only` on 5/5 seeds with a CI excluding zero. The little it learns transfers.
3. **Does it contribute beyond A?** Statistically yes, **practically no** — a
   3.6% MSE reduction where correct featurisation achieves exactly 0.

## Honesty about this test's design

The interacting targets are **exactly linear in an explicit finite basis**
(`1`, `z`, co-occurring products), which hands the win to ridge by construction.
That is a limitation of my task design, not proof that a residual can never help.

It is also not an excuse. On the tasks actually run, the residual is not useful,
and that is the finding. Both statements stand together.

A fair retest needs targets **not** exactly representable in a small explicit
basis — for example a saturating or thresholded functional of the structure, a
count of connected components, or a max over the selected edges. Those are the
regime where an MPNN could plausibly beat explicit-basis regression.

## Defects found in this stage's own code

Reported because they changed results in the method's favour before being fixed:

| Defect | Effect | Fix |
|---|---|---|
| interaction pairs keyed on vertex-**sharing** edges | on matchings those pairs can never co-occur, so the "interacting" target was **silently additive** (mixed differences 3.3e−16) | key on pairs that co-occur in at least one member |
| the same wrong condition in `ridge_pairwise` | the **strong baseline collapsed onto the additive one** — identical MSE to 4 dp; on path_matching the two pair sets have **zero overlap**, so all 168 product features were identically zero | one shared `cooccurring_pairs` helper used by target and baseline |
| comparing arms by independent means ± SD | arms share seeds, split and target; seed variance was not removed | seed-paired contrasts with paired CIs |

The first S4/S5 table was produced against the weakened baseline and was
discarded, not reported.

## Recommendation

**Do not scale up to P2 on this evidence.** The plan's rule is explicit: if no
useful nonlinear signal survives the bounded repair, do not spend the remaining
budget verifying that model at scale. A-initialisation is a genuine mechanism
result worth keeping; it is not a predictive result.

Smallest material redesign, in order:

1. **Retest on non-basis-representable targets** (saturating, thresholded, or
   count-of-components functionals). This is the fair version of the test just
   run and is cheap — S5 cost 0.03 GPU-hours.
2. **If the residual still loses**, the honest conclusion is that this operator
   class does not carry useful predictive interaction, and the contribution must
   be repositioned on verification rather than prediction — which requires your
   decision, since it narrows the paper's claim.
3. **Do not** add attention, depth, or another learned component to close the
   gap. The plan forbids it and it would not address the representational limit
   identified above.
